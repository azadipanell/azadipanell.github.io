01کلاینت شماYour client

v2rayNG یا Hiddify یک اتصال WebSocket معمولی روی 443 باز می‌کند — از بیرون شبیه هر سایت HTTPS دیگر.

v2rayNG or Hiddify opens an ordinary WebSocket on 443 — from outside it looks like any HTTPS site.

02عبور از فیلترThrough the filter

مقصد، یک IP از شبکهٔ Cloudflare است؛ همان شبکه‌ای که هزاران سایت روی آن است. بستنش یعنی بستن نیمی از وب.

The destination is a Cloudflare IP — the same network thousands of sites live on. Blocking it means blocking half the web.

03Worker شماYour Worker

کد نیکا نت روی لبهٔ Cloudflare اجرا می‌شود: کاربر را از D1 چک می‌کند، سهمیه را می‌شمارد و ترافیک را رله می‌کند.

Nika Net runs on Cloudflare's edge: checks the user in D1, counts quota, relays the traffic.

You want a stable connection for 5–30 family members and friends without paying for a server every month or re-sharing configs every week.

◔واقعیت‌های پلن رایگان — قبل از نصب بخوانیدFree-plan realities — read before you install

ما ترجیح می‌دهیم همین‌جا صادق باشیم تا شما بعد از نصب غافلگیر نشوید. این‌ها محدودیت‌های Cloudflare است، نه انتخاب ما.

We would rather be honest here than surprise you after install. These are Cloudflare’s limits, not our choices.

100k
درخواست در روز روی پلن رایگان Workers؛ برای یک جمع کوچک تا متوسط بیش از کافی است، برای صدها کاربر فعال نه.requests per day on the free Workers plan — plenty for a small to medium group, not for hundreds of heavy users.
10 ms
زمان CPU برای هر درخواست؛ رله‌ی WebSocket سبک است ولی استریم ۴K چند نفر هم‌زمان را نمی‌کشد.CPU time per request — the WebSocket relay is light, but several simultaneous 4K streams will not fit.
5 GB
فضای D1 رایگان (کاربران، تنظیمات، لاگ). عملاً هیچ‌وقت پر نمی‌شود.free D1 storage (users, settings, log). In practice you will never fill it.
TCP
فقط ترافیک TCP روی WebSocket؛ UDP ندارد — تماس صوتی/تصویری و بعضی بازی‌ها روان نیستند (WARP در نقشهٔ راه است).TCP over WebSocket only; no UDP — voice/video calls and some games will not be smooth (WARP is on the roadmap).
  • اگر بیش از ~۵۰ کاربر فعال هم‌زمان دارید، به پلن ۵ دلاری Workers یا یک VPS نگاه کنید.If you have more than ~50 concurrently active users, look at the $5 Workers plan or a VPS.
  • دامنهٔ workers.dev در ایران گاهی فیلتر است؛ یک دامنهٔ شخصی (حتی رایگان) و یک IP تمیز عملاً لازم است. راهنماworkers.dev is intermittently blocked in Iran; a personal domain (even a free one) and a clean IP are practically required. Guide
  • Cloudflare می‌تواند سرویس را قطع کند اگر مصرف غیرعادی تشخیص دهد؛ حساب اصلی کاری‌تان را برای این کار استفاده نکنید.Cloudflare can suspend the Worker if it flags abnormal usage; do not use your primary work account for this.
  • ناشناسی مطلق نمی‌دهد — Cloudflare ترافیک را می‌بیند. برای عبور از فیلترینگ عالی است، برای پنهان شدن از Cloudflare نه.It does not give absolute anonymity — Cloudflare sees the traffic. Great for bypassing filtering, not for hiding from Cloudflare.

نصب سریعQuick startThree steps

در سه قدم، پنل خودتان را روی حساب رایگان Cloudflare بالا بیاورید.

Bring up your own panel on a free Cloudflare account in three steps.

shahyad@studio — zsh

ترمینال بلد نیستید؟ با یک کلیک، Cloudflare ریپو را فورک می‌کند و Worker + دیتابیس را خودش می‌سازد.

No terminal? One click and Cloudflare forks the repo and provisions the Worker + database for you.

Deploy to Cloudflare
1

ساخت دیتابیس D1Create a D1 database

یک دیتابیس بسازید و database_id را در wrangler.toml قرار دهید.

Create the database and paste its database_id into wrangler.toml.

npx wrangler d1 create nika-net-db
2

بیلد و دیپلویBuild & deploy

یا فایل dist/_worker.js را در داشبورد Cloudflare پیست کنید و بایندینگ D1 با نام DB بدهید.

Or paste dist/_worker.js into the Cloudflare dashboard and add a D1 binding named DB.

npm install
npm run build
npx wrangler deploy
3

راه‌اندازیSet up

آدرس Worker را باز کنید، نام‌کاربری و رمز ادمین بسازید، اولین کاربر را اضافه کنید و لینک اشتراکش را بدهید.

Open your Worker URL, pick an admin login, create the first user and share their subscription link.

# structure
src/worker.ts   # entry & routing
src/protocols/  # VLESS & Trojan relay
src/cores/      # clash / sing-box / base64

لانچر پنل است: پنل شما را مستقیم از تلگرام باز می‌کند تا نیازی به حفظ آدرس و مسیرهای تصادفی نداشته باشید.

«تا کجا» رایگان است؟ محدودیت‌ها چیست؟+

پلن رایگان Workers روزانه ۱۰۰٬۰۰۰ درخواست و ۱۰ میلی‌ثانیه CPU برای هر درخواست می‌دهد و فقط TCP روی WebSocket را رله می‌کند (UDP ندارد). برای یک جمع کوچک تا متوسط کافی است؛ جزئیات صادقانه را در بخش «برای چه کسی است؟» نوشته‌ایم.

دامنهٔ workers.dev فیلتر است؛ چه کنم؟+

یک دامنهٔ شخصی (حتی رایگان مثل dpdns.org یا eu.org) به Cloudflare اضافه کنید و Worker را روی آن Route بدهید؛ سپس در تنظیمات پنل یک IP تمیز وارد کنید. قدم‌به‌قدم در راهنمای دامنهٔ شخصی و Clean IP.

رمز ادمین را فراموش کردم / از داده‌ها بکاپ می‌خواهم+

همه‌چیز در D1 خودتان است. با یک دستور wrangler d1 execute می‌توانید رمز را ریست یا از کل جدول خروجی JSON بگیرید — راهنمای بکاپ و بازیابی.

سایت شهیاد از من چه اطلاعاتی جمع می‌کند؟+

هیچ آنالیتیکس یا ردیابی‌ای روی این سایت نیست. تنها داده‌ای که ذخیره می‌شود، یادداشت‌هایی است که خودتان در صندوق پیشنهادات می‌فرستید (متن، نام مستعار و یک هش نمک‌دار از IP برای جلوگیری از اسپم). از پنل نیکا نت هم هیچ داده‌ای به ما نمی‌رسد؛ کد تلمتری ندارد.

چطور کمک کنم یا مشکل گزارش دهم؟+

ابتدا بخش عیب‌یابی مستندات را ببینید. سپس در GitHub یک Issue یا Pull Request باز کنید، یا در کانال @shahyad_asr پیام بگذارید. مشارکت همیشه خوش‌آمد است.

Is Nika Net really free?+

Yes. MIT-licensed and designed for Cloudflare's free Workers + D1 tier. Zero server cost — only Cloudflare's free-plan limits apply.

Which clients are supported?+

Anything speaking VLESS or Trojan over WebSocket: v2rayNG, Hiddify, Streisand, Clash/Mihomo, Sing-box… the sub link auto-detects the client format.

Where is my data stored?+

Only in your own Cloudflare account (D1). There is no middle server and the SHAHYAD team has no access to anything.

What does @NikaNettbot do?+

It is the panel launcher — it opens your panel from Telegram so you never have to remember randomized paths.

How free is “free”? What are the limits?+

The free Workers plan gives 100,000 requests per day and 10 ms of CPU per request, and relays TCP over WebSocket only (no UDP). Enough for a small to medium group; the honest details are in the “Who is it for?” section.

workers.dev is blocked for me — what now?+

Add a personal domain (even a free one like dpdns.org or eu.org) to Cloudflare, route the Worker to it, then set a clean IP in the panel settings. Step by step in the custom domain and Clean IP guides.

I forgot the admin password / I want a backup+

Everything lives in your own D1. One wrangler d1 execute command resets the password or dumps the whole table to JSON — see the backup & recovery guide.

What does the SHAHYAD site collect about me?+

No analytics or tracking on this site. The only stored data is what you submit to the suggestion box (text, nickname and a salted IP hash for spam control). Nothing reaches us from the Nika Net panel either — the code has no telemetry.

How can I contribute or report a bug?+

Open an issue or PR on GitHub, or drop a message in @shahyad_asr. Contributions are always welcome.
